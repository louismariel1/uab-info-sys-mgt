#  Centralized Hospital Laundry Location

# 1\. Introduction

## 1.1 Project Context

This project aims to identify the **best location for a centralized industrial hospital laundry serving hospitals in Vallès Occidental, Catalonia**.

The proposed laundry would collect soiled textiles from the hospitals, process them at a centralized industrial facility, and return clean textiles to the hospitals. Because transportation would take place between the laundry and several hospitals, the location of the facility is a key factor affecting both **operational efficiency and cost**.

The project therefore combines geographical, operational, economic, and practical considerations to identify the most suitable location.

## 1.2 Project Objective

The main objective is:

> **To select a real, currently available industrial premise that provides the best overall location for a centralized hospital laundry serving Vallès Occidental.**

The location will be evaluated using the four methods required by the project:

1. **Center of Gravity Method** — identifies the theoretical geographical centre of demand.
2. **Factor Rating Method** — compares candidate locations using factors such as accessibility, cost, infrastructure, and suitability.
3. **Cost Model** — compares the estimated total operating and transportation costs of the candidate locations.
4. **Graph-Based Models** — uses the road network to evaluate weighted distances and hospital coverage through the Simple Median and Coverage Models.

The results of these methods will be compared before making the final selection.

## 1.3 Study Area and Hospitals

The study focuses on the **Vallès Occidental** comarca, including the main hospital centres around Sabadell, Terrassa, Sant Cugat del Vallès, Cerdanyola del Vallès, Barberà del Vallès, and surrounding municipalities.

The initial analysis considers five major hospitals:

| Hospital | Municipality | Initial Demand Weight |
